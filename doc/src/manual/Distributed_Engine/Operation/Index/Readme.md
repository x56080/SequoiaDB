    操作指南-索引 Readme

索引是一种提高数据访问效率的特殊对象。创建索引后，SequoiaDB 巨杉数据库可以通过特定字段的值快速定位到匹配的记录，大大提升查询效率。

SequoiaDB 根据不同的查询需求，提供了不同类型的索引。通过本章文档，用户可以了解各索引的介绍及使用。主要内容如下：

- [单字段索引][single_field_index]
- [复合索引][compound_index]
- [唯一索引][unique_index]
- [全文索引][text_index]
- [独立索引][standalone_index]
