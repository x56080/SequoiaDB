    操作指南-索引 Readme

索引是一种提高数据访问效率的特殊对象。创建索引后，SequoiaDB 巨杉数据库可以通过索引查找特定值，以快速定位到匹配的记录，大大提升查询效率。

SequoiaDB 根据不同的查询需求，提供了不同类型的索引。通过本章文档，用户可以了解各索引的介绍及使用。主要内容如下：

- [普通索引][normal_index]
- [唯一索引][unique_index]
- [全文索引][text_index]
