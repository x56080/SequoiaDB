SdbSchema 类主要用于操作 Schema，包含的函数如下：

| 名称                         | 描述                   |
|------------------------------|------------------------|
| [addColumn][addColumn]       | 新增 Schema 的字段     |
| [alterColumn][alterColumn]   | 修改 Schema 的字段定义 |
| [dropColumn][dropColumn]     | 删除 Schema 中的字段   |
| [renameColumn][renameColumn] | 重命名 Schema 中的字段 |
